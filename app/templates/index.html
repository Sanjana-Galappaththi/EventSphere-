Multi-Agent System Architecture

How the 5 Autonomous Agents Cooperate

Structured FIPA performatives: REQUEST, AGREE, REFUSE, PROPOSE, INFORM, FAILURE

VenueAgent
Goal: Zero Calendar Clashes

Guards every space calendar. Enforces a 30-minute turnaround cleaning buffer, evaluates private hire requests against capacity, computes weekend peak surcharges (+50%), and formulates alternative slots via PROPOSE when dates clash.

Turnaround Buffer Peak Pricing Counter-Proposals
BookingAgent
Goal: Fair, Zero-Overselling

Applies strict limits (≤ 6 tickets). Uses database row-locking (with_for_update) to ensure two users booking the final seat simultaneously never oversell. Computes tiered refund rules (≥ 7 days = 100%, < 7 days = 50%) and triggers automatic full refunds on cancellations.

ACID Locking Refund Policy Event Cascade
TicketAgent
Goal: Admit Exactly Once

Generates unguessable 256-bit cryptographically random tokens and renders scannable QR passes. Enforces check-in windows (-2h to +1h). Rejects duplicate scans with explicit reasons and detects potential fraud via suspicious repeat scan thresholds.

Unguessable QR Check-in Windows Anti-Fraud Detection
WaitlistAgent (Proactive Autonomous Timer)
Goal: Fair Seat Re-allocation

Maintains persistent FIFO waiting queues. When seats are freed, it places 15-minute exclusive holds. Running on an autonomous background timer (APScheduler) without human intervention, it proactively sweeps expired holds and cascades seats to the next waiting customer.

Autonomous Timer Sweep 15-Min Timed Holds FIFO Cascade
NotificationAgent
Goal: Event-Driven User Dispatch

Acts as a universal listener for all broadcast INFORM and PROPOSE messages. Transforms internal MAS decisions into clear, actionable notifications for attendees, including seat release offers, cancellation refunds, and hire approval statuses.

Reactive Listener Live Feed Message Logged
